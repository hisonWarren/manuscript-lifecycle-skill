# 稿件评估量表与选版规则

先定本次阶段、适用类型、输入版本和读者，再评分。分数是项目工作标准，不是科学验证或发表概率。

**阻断清单先于分数**：捏造结果/引用/审批、错误的承重数字、关键不利/预定结果遗漏、过度因果/推广、声称改动未落地、当前版本未检查。任一存在，不可用其他高分抵消。

每维 0–3：0=缺失/错误；1=仍有实质缺陷；2=满足本任务基本职责且保留少量有理由例外；3=依据充分、读者可理解、复查无实质问题。每分有具体段落或证据链接，并标自评/隔离模型评审/人评。没有依据不给分。

| 维度 | 看什么 |
|---|---|
| 主线 | 问题、发现、四处概括一致；方法论文允许方法主线 |
| 类型/推断 | 体裁、设计、贡献和语言匹配 |
| 章节职能 | 服务本节任务；情境例外合理，非单纯 linter 计数 |
| 报告完整与分配 | 主要/预定/不利结果完整，细节位置有依据 |
| 方法可读与复现 | 目的清楚，必要设置完整，软件/样本范围准确 |
| 数字与边界 | 身份、符号、分母、单位、模型、区间与来源相同 |
| 讨论论证 | 有价值的解释、可比证据、适度含义与边界，非凑阶梯 |
| 信息经济 | 每段有任务，删后不丢承重内容，无无效扩展 |
| 语言与声音 | 标准术语、作者判断、语气和连贯；分布仅辅助 |
| 引用与材料 | 关键引文上下文核实，交付件自足一致，图注表注适当 |

适用维度有明示 N/A，不能无依据给满分。分数不直接跨不同案例或不同维度集合比较。

收敛：无阻断且每个适用维度至少 2；连续两轮对当前版本复查无新重大问题且无核心退步；同一任务下主要分歧只剩有理由偏好。若仍有重大问题，停止仅可称暂停/需信息，不能称达标。

选版：在满足硬条件的候选中比较维度证据、作者目标与改动代价；总分仅作参考。保存胜出理由及备选，不以最新版本或最高风格分自动胜出。

skill 自评另加：多类型路由、空/缺/陈旧证据拒收、合理例外不误杀、脚本实跑、注释/投稿包可用性、全局同类问题扫描、过程/用户材料区分。模拟不等于真实稿件或跨学科验证。
