# 14 · 中文稿：摘要、讨论首段、结论
<!-- test: tool=lint section=zh design=cross_sectional bad=S1,S2,D1,D2 good_no=S1,S2,D1,D2 -->

任务：同样的章节职责，用中文学术写作的习惯表达。

## 坏例

```bad
## 摘要

本研究基于正则化偏相关网络分析框架，对寄宿制与走读制中学生抑郁症状的网络结构进行了深入的探讨与分析。研究结果表明，睡眠问题是抑郁症状网络的核心驱动因素，在一定程度上可能发挥着重要的作用。两组网络结构完全一致，而寄宿生的整体连接强度显著更高，这意味着寄宿环境导致了症状间的相互强化。此外，低基线亚组呈现出更强的获益趋势，虽然未达到显著性水平，但仍值得关注。

## 讨论

在本研究中，我们发现 M = 0.14（p = .41），整体强度为 3.92 与 3.41（p = .02），具体见 3.2 节和表 1。综上所述，这些结果充分表明了关注学校环境的重要意义。
```

## 为什么坏

1. **“对……进行了深入的探讨与分析”**：拖沓的“进行”结构，把一个动词拆成了三个词。改成“比较了……”。
2. **“核心驱动因素”**：横断面数据写成了因果。
3. **“在一定程度上可能……发挥着重要的作用”**：三层模糊限定连用，读完不知道结论是什么。
4. **“完全一致”**：把不显著说成了相同。
5. **“虽然未达到显著性水平，但仍值得关注”**：把不显著写成半个显著，这是典型的结果粉饰。
6. **讨论首段报统计量、回指章节号**：中文的“见 3.2 节和表 1”和英文的 see Section 3.2 一样，让讨论不能独立读懂。
7. **“综上所述，这些结果充分表明了……重要意义”**：套语收尾，换到任何一篇论文都成立。

## 改写

```good
## 摘要

抑郁症状很少单独出现，症状之间如何关联可能随生活环境不同。本研究比较了寄宿制与走读制中学生的抑郁症状关联模式。2140 名中学生的结果显示，两类学校学生的症状关联模式相似，但寄宿生的症状之间联系更紧；两组中与其他症状联系最多的都是睡眠问题。差别在于症状共同出现的紧密程度，而不在于哪些症状相互关联。本研究为横断面设计，关联的方向需要追踪数据才能判断。

## 讨论

寄宿生与走读生的抑郁症状关联模式相似，但寄宿生的症状之间联系更紧。两组中与其他症状联系最多的都是睡眠问题，联系最紧的一对都是情绪低落与兴趣减退。两类学校的差别体现在症状共同出现的紧密程度上，至于哪些症状彼此关联，两组基本相同。
```

## 中文稿另外要盯的几处

- **少用“进行”**：“对 X 进行分析”改为“分析 X”。
- **少用三层以上的“的”字定语链**，如“基于多模态数据的在线学习行为的识别的方法”。
- **少用“被……所”**，少用“作为……，……”起句，少用“在……的背景下”。
- **术语**：首次出现时给英文与缩写，之后只用一种说法。
- **标点**：用全角标点；中英混排是否加空格按期刊要求。
- **公文套语**：“赋能”“抓手”“闭环”不进研究论文。

## 这份范例不校准什么

- 中文结论通常比英文长，有些刊还要求分条写；不要用英文的字数上限去卡中文结论。
- 有些中文刊把研究问题写在文献综述之前，这是学科惯例，不是缺陷。
