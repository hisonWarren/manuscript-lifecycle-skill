# 结果与方法记录（合成数据，不代表真实研究）

## 设计与样本
- 横断面问卷调查；某省 6 所中学（3 所寄宿、3 所走读），2,315 名学生参与。
- 分析前规定：缺答超过 20% 条目者不纳入（175 人）。分析 2,140 人：寄宿 1,032 人，走读 1,108 人。其余缺失（<1%）用成对完整观测处理。
- 抑郁症状：PHQ-8 的 8 个条目（不含自伤条目），自评，近两周。
- 伦理审批：编号待作者提供。

## 分析（作者原始笔记，方法细节偏多）
- 正则化偏相关网络（EBICglasso，tuning γ = 0.5，Spearman 相关），节点为 8 个症状；中心性指标为预期影响（expected influence, EI）。
- 稳定性：case-dropping bootstrap，1,000 次，CS 系数（通常以 ≥ 0.5 为可接受）；边权准确性：非参数 bootstrap，1,000 次。
- 网络比较检验（NCT，1,000 次置换），比较寄宿与走读：网络结构不变性（预定，H1）与整体连接强度（预定，H2）。
- 边特异性差异：未计划，28 条边逐一检验（探索性）。
- 软件：R 4.3.2；qgraph 1.9.8；bootnet 1.5.6；NetworkComparisonTest 2.2.2。

## 结果
- H1 结构不变性：M = 0.14，p = .41（未见结构差异的证据）。
- H2 整体强度：寄宿 3.92，走读 3.41，差 0.51，p = .02。
- 两组预期影响最高的都是“睡眠问题”：EI 寄宿 1.21、走读 1.15。
- EI 的 CS 系数：寄宿 0.67，走读 0.59。
- 探索性边差异：28 条边中 3 条在未校正 p < .05 下不同；Holm 校正后 0 条。
- 最强的边：两组都是“情绪低落—兴趣减退”（寄宿 0.31，走读 0.29）。
