# Leveraging Regularized Partial Correlation Network Analysis to Unravel the Intricate Symptom Architecture of Adolescent Depression in Boarding and Day Schools

## Abstract

Using EBICglasso network estimation (γ = 0.5), case-dropping bootstrap (1,000 iterations; CS = 0.67) and the Network Comparison Test (1,000 permutations), we examined PHQ-8 symptom networks in 2,140 adolescents. Sleep problems emerged as the core symptom driving depression in both school types (EI = 1.21 and 1.15), indicating that sleep is a key intervention target. The networks were identical in structure (M = 0.14, p = .41), whereas boarding students showed significantly stronger global connectivity (3.92 vs 3.41, p = .02), suggesting that boarding causes more tightly coupled symptoms. Three edges were stronger in boarding schools.

## Methods

Random seeds were set to 2024. We re-ran the NCT after initially using the wrong grouping variable. Data were cleaned in Excel and converted to CSV.
