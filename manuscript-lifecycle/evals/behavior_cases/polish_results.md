# 研究结果摘要（合成）

设计：横断面问卷调查，某省 3 所高校 860 名本科生，方便抽样；所有变量均为自评。
变量：每日手机使用时长（小时，自评）；睡眠质量（匹兹堡睡眠质量指数 PSQI，分数越高睡眠越差）；抑郁症状（PHQ-9）。

主要结果：

- 手机使用时长与抑郁症状正相关，r = .21，95% CI [.14, .27]。
- 中介模型（Bootstrap 5000 次）：经睡眠质量的间接效应 b = 0.08，95% CI [0.05, 0.12]；直接效应 b = 0.11，95% CI [0.04, 0.18]。
- 性别调节：交互项 b = 0.03，95% CI [−0.02, 0.08]，p = .21。
- 控制年级与家庭月收入后，上述估计基本不变。

分析身份：相关与中介模型为预定分析；性别调节为事后探索。
未提供：理论框架相关文献、样本的回应率。

## 学生写的讨论第一段

旧讨论首段：本研究通过对 860 名大学生的问卷调查，发现手机使用时长与抑郁症状显著正相关（r = .21，p < .001），睡眠质量在其中起部分中介作用（间接效应 b = 0.08，95% CI [0.05, 0.12]；直接效应 b = 0.11，95% CI [0.04, 0.18]），间接效应占总效应的 42.1%。性别的调节作用不显著（b = 0.03，p = .21），但女生的效应呈现出更强的趋势。具体结果见 3.2 节和表 3。这说明手机使用会通过破坏睡眠导致抑郁，证实了我们的假设。

## 学生写的结论

旧结论：综上所述，本研究证实了手机使用通过降低睡眠质量进而导致大学生抑郁症状增加，睡眠质量起到了部分中介作用，这一发现具有重要的理论意义和实践价值，填补了国内该领域研究的空白。性别差异虽然不显著，但值得关注。因此，高校应当限制学生的手机使用时间，并开展睡眠健康教育，以有效预防和减少抑郁的发生。未来研究需要进一步深入探讨其内在机制，扩大样本量，采用纵向设计，为大学生心理健康教育提供更加科学的依据。
