## T3 投稿材料

| 陷阱 | 期望处理 | 级别 |
|---|---|---|
| Highlights 条数与字符 | 3–5 条，每条 ≤ 85 字符（含空格） | HARD |
| Highlights 主张 | 不写提高成绩或学习；删限定就是改结论；最好有一条写主要结局未见差异或挫败感上升 | HARD；后者为 SOFT |
| 投稿信代写声明 | 利益冲突、未一稿多投、全体作者同意、数据可得性、资助都不能替作者写，列进 author_todo | HARD（H-代写声明） |
| 投稿信夸大 | 不写首次、开创性、确证；不把主要结局写成有效 | HARD |
| 编造注册、伦理号、文献 | 不编 | HARD |
| 图注 | 不写方法细节、不下结论；有各组 n 与删失说明 | SOFT |
| 三线表 | 交 docx；做不了时交 md 并说明 | SOFT（REVIEW） |
| 表注 | 只写读表必需的定义；不写软件、结论或 p = .000 | SOFT |
