# 29 · 选材与同类调研：论文不是项目档案

一次实测暴露了这一页要解决的问题。一个实证项目留下了一整套结果语料，执行者据此起草论文，把项目里做过的每项分析都当成论文欠读者的东西。未收敛的模型、经典对照失败的指标、只在换了一种预处理后才出现的条件效应、随基线定义翻转的关联，一律标成“必须披露，不能删”，再分进主文或补充。

这些判断都能在本技能里找到依据：

- 03 写过“已经做过的分析不选择性隐去”；
- 披露判断把“分析失败”列为必须披露的条件；
- 去向登记只罚“该写的没写”（PL4），不罚“不该写的写了”。

而且这些判断是在读同类论文之前、在作者说出想发表什么之前作出的。

作者的批评是：

- 一篇论文用不上项目里的所有分析；
- 要先看同类论文为什么只呈现那些；
- 要从作者想呈现什么、审稿人看到会怎样反应出发选材；
- 不适合放的不放，免得引来一堆答不了的追问。

## 1. 逻辑：论文是作者对读者的一次论证

论文要读者相信一件事。它在有限的篇幅和注意力里，用最能支撑这件事的证据把它说清。所以选材是作者的核心工作，放进来的每一项都要挣得位置。决定一项材料放不放、放在哪里，要同时看五个视角：

| 视角 | 问的问题 | 只看这一个会怎样 |
|---|---|---|
| 作者目的 | 它服务哪条主张？删掉它，读者对贡献的理解少了什么？ | 只挑显著的，滑向选择性报告 |
| 审稿人反应 | 放了，审稿人会问什么，我们答得了吗？不放，审稿人会问“为什么没做”吗？ | 为躲追问，删掉与主张相关的不利证据 |
| 同类惯例 | 同类论文在这里呈现什么、呈现多少、放在哪里？ | 照搬近邻，不管本稿主张 |
| 诚信底线 | 不放它，读者对主张的判断会不会比看到全部相关证据时更乐观？ | 把项目档案当论文，做过的全写（本技能曾经的偏差） |
| 现实策略 | 它是不是另一篇论文的材料？现在放进来会不会冲淡本文，又浪费那一篇？ | — |

本技能过去只把第四个视角写成了硬规则，而且写宽了：交代义务按“做过什么”算，而不是按“主张什么”算。罚则也是单向的，漏写受罚，滥放不受罚。按规则办事的执行者自然越放越多，写出来就是实验报告。

审稿人追问分两种，选材要同时照顾：

- **放了引起的追问**：失败的模型、解释不了的指标、与主线无关的分析，都在给审稿人递问题。
- **缺了引起的追问**：同类论文都会报告、本稿却没有的分析，审稿人会问“为什么没做”。

所以目标不是“越少越好”，而是在同类惯例的范围里，只呈现服务主张、能经得起追问的材料。

## 2. 交代义务跟着主张走，不跟着项目历史走

一项分析必须在论文里交代（至少放在补充里，并在正文给入口），只在有下列依据之一时成立。去向登记的 `disclosure_basis` 只取这五个值：

| 依据 | 含义 | 例子 |
|---|---|---|
| registered | 预注册、方案、注册报告或已公开的分析计划里写过 | 注册的主要结局 |
| claim | 本文主张依赖它，或它会限定本文主张：同一主张的其他合理设定、失败的稳健性检验、同一构念的其他测量，以及被选中的发现是在多少种设定里找到的 | 主张“干预提高了成绩”；换一种缺失数据处理后效应不再成立，这个结果限定了该主张 |
| data | 影响已报告结果的数据、样本或变量问题与计划偏离 | 随访脱失或记录对齐失败，部分分析只剩一部分参与者 |
| journal | 目标刊或报告规范的要求 | 期刊要求列出全部结局 |
| ethics | 伦理、同意、利益冲突、资助、数据可得性等事实声明 | — |

没有依据的分析不是交代义务。它放不放、放在哪里，由作者目的、审稿人反应和同类惯例决定，**默认不进本文**。它可以留在项目档案里备审稿人问（reserve），也可以另写一篇（omit，写明“可作他文”）。这不是隐瞒：论文的范围由研究问题决定，作者有权选择问题。

### 结果盲测试：范围不能看结果来定

问题之内不能挑结果。判断一项材料属不属于本文，先问：**如果它的结果正是你希望的样子，你会把它放进论文吗？**

- **会**（放主文或补充）：它和主张相关。结果不理想时也要交代，或者把主张收窄，并说明收窄的原因。去向登记的 `if_favorable` 写这个“理想时的去向”，脚本核对实际去向有没有因为结果不好而下沉（genre_gate PL9）。
- **不会**：它不属于本文问题，结果好坏都不放，不算隐瞒。

合法的做法有两种：

1. 交代与主张相关的不利结果；
2. 选一个更窄、证据更扎实的问题，让无关的分析真正落在范围之外。

不合法的做法：保留宽的主张，却删掉检验这条主张时失败的分析。看完结果才收窄问题时，保留下来的发现要标为探索性，并写明它是在多少种设定或测量里找到的。

“审稿人可能会问”只说明要备好答案，不说明要写进论文（reserve）。“同类论文不写”只能影响篇幅和位置，不能免除有依据的交代。

## 2b. 结果盲测试问的是哪条主张

if_favorable 只在一项分析**检验已登记的某条主张**时才有约束力：先写它检验哪条主张（C1…），再问结果理想时放哪里。如果它结果理想时只会**新增**一条原来没有的主张（例如本文不谈决策参数，DDM 收敛良好时会多出“情绪作用于漂移而非起点”），那是范围扩张：claim 记 none，function 记 preempt 或 out_of_scope，if_favorable 记 reserve 或 omit，理由写清。未收敛、未注册、也不限定任何已登记主张的模型据此默认备答；作者确认它是预注册或公开计划的分析时（registered），改进补充简短交代。注意不要在讨论里提出只能由备答分析回答的问题来“制造”相关性。

## 3. 顺序：先调研，再构想，再选材

顺序错了，后面全错。那次失败里，去向是在读同类论文之前、在作者说出想发表什么之前定的。正确的顺序是：

1. **清点（S0–S1）**：每项分析是什么、样本多大、证据质量如何。证据质量取 robust（稳健）、fragile（依赖设定）、failed（失败）、uninterpretable（无法解释）、descriptive（描述性）。这一步不定去向，也不对作者说“必须披露”。
2. **同类调研（S2）**：见 §4。
3. **构想（S3 前半）**：从作者目的出发，写一到三个候选论文构想（`paper_concept.md`）。
   - 材料足以写成不止一篇时，“这一篇写哪一篇”就是会改变主线的问题：摆出候选构想与各自的材料和风险，请作者选。
   - 作者没回答时，按推荐的一个推进，并在作者说明里写明。
4. **选材（S3 后半）**：对选定的构想逐项登记去向（§5）。
5. **体裁蓝图**：六个节职能维度（[27](27_genre_and_placement.md)）。

S2、S3 完成前，可以给作者材料清点和调研计划，不给“放主文、放补充、必须披露”这类结论。

## 4. 同类调研：弄清同类作者为什么只呈现这些

目的不是找几篇论文模仿句子。要弄清的是：这一类论文的作者通常选择呈现什么、呈现多少、为什么；审稿人在这类论文上通常追问什么。

**范围：多维相似。** 按下面的维度分别检索，每篇在 `survey_corpus.csv` 的 axes 列标出它匹配哪些维度：

| 维度（axes） | 找什么 |
|---|---|
| topic | 同一现象或问题 |
| field | 同一领域与读者 |
| method | 同一测量或技术（如量表、脑电、访谈、机器学习模型） |
| analysis | 同一分析策略（如逐试次脑–行为关联、解码） |
| framing | 同一背景或理论争论 |
| journal | 目标刊或同刊的近期论文 |
| flagship | 设计相近的高影响刊论文，学写法的上限 |

**数量。** 下面是默认值，可以按领域与模式调整：写进 `survey_scope.json` 并写理由，survey_check 用 SV8 核对（§10）。默认值：

- 筛选不少于 20 篇（读题目和摘要，记录类型是否匹配）；
- 至少覆盖 3 个维度；
- 全文编码不少于 6 篇，其中类型匹配的不少于 4 篇。

只读到摘要的论文不能编码选材。类型不对的论文（综述、方法论文、纯行为短报告）可以当反例，不进惯例统计。

全文拿不到（出版社拦截、没有网络）时，尽早把 DOI 清单交给作者，不要花掉大半额度硬抓，也不停工。分布结论写明比了几篇、含不含目标刊；缺目标刊时标“暂定”，补进来后结论变了要明说更正。

**编码（每篇全文）。** 记录以下几项：

- 主文报告了几项分析、几张图表，补充材料有几项；
- 测了哪些指标、报告了哪些；
- 能推断出做过却没报告的分析，写在 omitted_but_possible；
- 探索性和不显著的结果怎么处理。

同一批全文也用来填 [27](27_genre_and_placement.md) 的六个节职能维度（摘要末句、引言首末段、方法粒度、主文表型、讨论首段）：调研一次，两处用。

最关键的一栏是 `why_only_these`：用一两句话推断作者为什么只呈现这些，他们的主张需要什么、不需要什么。写不出来，说明还没读懂这篇。

**综述（`survey_synthesis.md`）。** 分四节：

1. 同类论文通常呈现什么：分析数、图表数、补充项的范围；
2. 他们为什么只呈现这些：选材的逻辑；
3. 审稿人在这类论文上常问什么：公开审稿意见与编辑评估最直接；
4. 对本稿的含义：材料预算，即主文大约几项分析、补充大约几项，以及哪些是这类论文不提就会被问的。

**取材条件。** 有网时真取全文，并记录访问程度。只有搜索摘要时按 [23](23_literature_evidence.md) 的表降级，不写“已调研”。没网、作者也没提供全文时，S2 标 blocked，note 写“缺材料：近邻全文（至少 6 篇，类型……）”。

**两轮调研。** 第一轮宽，覆盖所有候选构想可能涉及的维度。构想选定后补一轮窄的，专找与选定构想最接近的论文。

## 4b. 表面惯例画像

对标决策表的六个节职能维度之外，题目、补充称呼、局限版式、讨论小标题、摘要结构这类惯例同样需要外部尺子，否则会退回范例或检查器的默认写法。S2 全文编码后运行 `convention_profile.py`（`--titles survey_corpus.csv` 用调研表的题目扩大参照，类型匹配 ≥5 篇时以类型匹配者为准；`--term-groups` 写刺激、构念等术语组）。S3 对每个偏离在 benchmark_decisions.csv 写 `convention:<维度>` 行：采用多数做法，或保留并写理由（例如刺激类型是本文的独特变量，题目点名它）。genre_gate CN1 在 S5 核对。

## 4c. 偏离登记：近邻能测的写法都进同一张表

第四轮加了表面惯例画像；第五轮用户又指出两类违和：引言末段的语步组成，以及标点、句长、转折词、人称这类文本质感。工具其实都在（move_check、bench_profile、phrase_contrast），只是没有一站要求运行，结果也没人读。与其每次再加一维，不如把“近邻能测的写法”统一起来：

`deviation_register.py` 一次收集四类偏离——惯例（convention_profile）、关键段语步（move_check）、文本质感（bench_profile：冒号、分号、破折号、括号、句长与长句、段长变异、连接词、限定与强化语、第一人称、否定、rather than、防御句式等）、词汇（对数似然 keyness，稿件多用而近邻少用的词）。

- 参照：S2 的类型匹配全文；有匹配的领域包时一并加入（`--baseline`）。对标 <10 篇看范围，10–19 篇看 p10–p90，≥20 篇看 p05–p95。
- 分类：惯例、语步与“文风类”质感（散文节的标点、句长、连接词、人称、否定；方法与结果节的标点、连接词、人称）必须裁决；内容驱动的质感（数字、引文、统计词密度）与词汇只列出供看。
- 裁决：benchmark_decisions.csv 的 dimension 写 `convention:…`、`move:…`、`texture:<节>:<指标>`（可用 `texture:*:<指标>`）、`lexis:<词>`；`--todo` 生成待填行。改的时候改原因（拆句、换连接、把限定移到它限定的句子），不为指标换同义词。
- 关口：genre_gate CN1、MV1、TX1（投稿阶段未裁决即 MUST），TX2、LX1 供看；station_check 的 S5 要求 genre_gate 结果里有语步对照（每单元 ≥3 篇）与质感分布。
- 计数口径：`[VERIFY: …]`、`[ref]` 等占位符在计数前去掉（第五轮实测：方法节冒号率因占位符虚高）。

实测：v2 待裁决 26 项（语步 4、质感 20、惯例 2）；v3 修改后剩 3 项，裁决保留后为 0。“看起来合理但有违和感”的来源，主要是摘要与讨论的长句和分号冒号、几乎不用 we、连接词低于同类下限（多半是去 AI 腔规则矫枉过正），以及段落长度整齐划一。

## 5. 选材：逐项写清为什么放、为什么不放

`placement_decisions.csv` 每项一行。同一块彼此相关、去向相同的分析可以合并为一行，如“探索性文本挖掘的全部分析”。列如下：

| 列 | 写什么 |
|---|---|
| claim | 它服务或限定的主张编号（来自 paper_concept 的 C1、C2…）；不相关写 none |
| function | core 主张的核心证据 / support 佐证 / qualify 限定或稳健性 / preempt 回应可预见的追问 / context 背景或样本描述 / out_of_scope 不属于本文 |
| evidence_quality | robust / fragile / failed / uninterpretable / descriptive |
| placement | main 正文 / supp 补充 / reserve 备答（不进论文，审稿人问到时用）/ omit 不属于本文（留在项目档案，可作他文） |
| if_favorable | 结果理想时你会把它放在哪里（结果盲测试） |
| reviewer_if_shown | 放了，审稿人会问什么或怎么看 |
| reviewer_if_absent | 不放，审稿人会不会问“为什么没有”，问了怎么答 |
| disclosure_basis | registered / claim / data / journal / ethics，可多个，用竖线分隔；没有就空着 |
| reader_question、neighbor、locator、reason | 同 [27](27_genre_and_placement.md) §4 |

**纳入的代价。** 每多放一项，都有代价：

- 读者多花注意力；
- 审稿人多一个可问的点；
- 多重比较的担心多一分；
- 最弱的那项分析，常常决定审稿人对整篇的印象。

所以纳入要有理由：服务主张、回应必然的追问，或者有交代依据。“做过”“可能被问”“不放可惜”都不是理由。

**失败与无法解释的分析。** 不服务主张、也没有交代依据的，不进补充，它们只会引来“为什么放一个失败的模型”。服务主张的，要么作为限定简短交代，要么收窄主张。

**补充材料不是仓库。** 补充的项数要与同类论文对照（PB1），超出范围要有理由。

## 6. 审稿人预判放在写稿之前

选材定下之后、起草之前，做一次审稿人预判，写在 `paper_concept.md` 第 5 节：

1. 按这套材料，列出审稿人最可能问的五个问题；
2. 逐个看现在答不答得了，答案在正文、补充还是备答材料里；
3. 答不了的，回头改选材或收窄主张。

有子代理时，派 `agents/reviewer_selection.md` 审选材方案。

拒收预演（S8）另有两条默认探针，方向相反，都要判定：

- **RJ9**：像项目档案，放了不服务主张、或会招来答不了的追问的分析；
- **RJ10**：与主张相关的不利结果被藏起或被下沉。

## 7. 和作者说话

去向结论用四种说法，不用一句“必须披露”：

- **与主张相关，必须交代**：写出依据，即哪条主张、哪类依据；
- **本文用**：放正文或补充，写出读者问题；
- **备答**：不进论文，审稿人问到时给出；
- **不属于本文**：留在项目档案，必要时写明“可作他文”。

论文写哪一个问题由作者决定（AU1）。执行者负责指出三件事：哪些选择会构成选择性报告；哪些材料放进来会招来答不了的追问；哪些是同类论文不提就会被问的。

## 8. 工具与关口

- **`survey_check.py`**：
  - 核对调研的广度：筛选数、维度数、全文编码数、类型匹配数；
  - 核对选材编码是否齐全，“为什么只呈现这些”是否模板化，综述各节是否填写；
  - 输出同类论文的材料范围（norms），供 genre_gate 的 PB1 使用。
- **`genre_gate.py`**：
  - 去向登记的新规则：
    - PL8 交代没有依据；
    - PL9 结果盲测试；
    - PL10 离题材料进了论文；
    - PL11 旧版登记缺选材字段；
    - PL12 失败分析当核心证据；
    - PL13 没有依据的失败分析进了补充；
    - PL14 缺审稿人两问；
    - PL15 主张编号在构想里找不到。
  - 论文构想：PC0 缺构想、PC1 构想有节没填或没有编号的主张。
  - 材料预算：PB1。
- **`station_check.py`**：
  - S2 要调研三件（survey_corpus、survey_synthesis、neighbors），并满足调研关口；
  - S3 要论文构想与新版去向登记。

脚本只核对一致性，不核对判断是否高明。读者问题、审稿人两问和“为什么只呈现这些”写得是否当真，靠 reviewer_selection、站点质检员与作者通读。

## 9. 边界

- 默认数字来自一个领域的经验。用于其他领域时，先在 3–5 篇近邻上看一遍，按领域调整，并写进决策登记。
- 结果盲测试依赖执行者如实填写 if_favorable。它能拦下同一行里自相矛盾的写法，拦不住整行造假。
- 预注册研究、注册报告和临床试验另有报告规范，以规范为准。
- 本页不替作者决定研究问题；它保证问题选定之后，选材有理由，交代有依据。

## 10. 不同模式、不同类型的论文怎样用

本页的做法不依赖某一领域或某一类数据。下面两张表说明它在各种场景下怎样落地。

| 场景 | 怎样用 |
|---|---|
| D 初稿、R 修订 | 全套都做：调研、构想、选材 |
| S 投稿准备（稿件已成） | 调研可以收窄到目标刊与旗舰刊，规模写进 survey_scope.json 并写理由；构想以现稿主张为准，重点查有没有滥放或藏匿 |
| V 返修 | 窄调研：主张已定，只比较受审各节与回应写法。init_project 预设筛选 10、全文编码 6、类型匹配 4、维度 2；近邻含目标刊（neighbors.csv 的 tier 写 target），拿不到写 exempt:target。比的是局限、讨论、方法和结果里新增内容在同类里的分布（07 §10）。审稿人要求的新分析也逐项登记去向：正文、补充，或只写在回复信里（reserve）。期刊要求写进论文的，以期刊为准；同样做结果盲测试 |
| A 只审不改 | 不要求产物；审稿时用五个视角与结果盲测试，指出滥放与藏匿 |
| 整篇修改、不重建（单文档修订） | 不做选材调研；体裁或写法问题读 3–5 篇类型匹配近邻（SKILL §0），说法写 case |
| 单句或局部修改 | 不走这一套 |

| 论文类型 | “分析”按什么计 | 特别注意 |
|---|---|---|
| 实证研究（实验、观察、问卷） | 带推断的分析块 | 预注册或注册试验的全部结局有 registered 依据 |
| 系统综述与元分析 | 合成分析、亚组与敏感性分析 | 报告规范（如 PRISMA）要求的条目有 journal 依据，不能按“用不上”删 |
| 质性研究 | 主题或发现 | 选哪些引语同样是选材；不支持主题的材料按 claim 依据交代 |
| 方法、模型与工具 | 实验、基准对比、消融 | 同类论文必有的基准与消融，缺了会被问 |
| 模拟研究 | 场景与参数网格 | 生成设定不是发现（[22](22_metrics_and_definitions.md)） |
| 理论、评论与观点 | 论证块 | 没有数据分析时，调研看结构与论证；n_main_analyses 记论证块数 |
| 短报告与快报 | 同上 | 篇幅更紧，补充与备答更常用 |
| 中文期刊 | 同上 | 调研按中文目标刊与同领域中文期刊找，体例以目标刊为准 |

**默认值与校准。** 调研的默认规模和体裁门的文本规则，最初是在神经科学与行为研究上校准的。用于其他领域时有两条路：

1. 调研规模写进 `survey_scope.json`。可以调低，但不能低于最低限度：筛选 5 篇、全文编码 2 篇、相似维度 2 个。
2. 给 genre_gate 提供本领域近邻全文（`--neighbor-texts`）。近邻里至少两篇、且至少三分之一也触发的文本规则，会自动降一级，并在报告里写明“近邻 k/n 篇同样触发”。

两条路都留下记录，别人能核对。

**没有网络时。** 只读到摘要的论文不能编码选材。作者能提供全文，就用作者提供的；提供不了，S2 标 blocked，写“缺材料：近邻全文”。不能写“已调研”。
