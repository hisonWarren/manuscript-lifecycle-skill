## 安装

将本仓库中的 `manuscript-lifecycle/` 目录放入 Cursor skills 路径，或直接使用发布包：

- [`manuscript-lifecycle.skill`](./manuscript-lifecycle.skill)

## 仓库内容

| 路径 | 说明 |
|------|------|
| `manuscript-lifecycle/` | Skill 本体（`SKILL.md`、agents、references、scripts、assets） |
| `manuscript-lifecycle.skill` | 可安装的 skill 压缩包 |

## 用途摘要

以研究问题、发现和证据为主线，核对数字口径、引文支持、选材与节职能；按任务性质（初稿 / 修订 / 投稿 / 返修 / 只审）灵活调用流程，局部请求保持轻量。
